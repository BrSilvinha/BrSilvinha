<summary><b>🧠 Sentinel Vision Platform</b> — Proyecto de tesis · IA / Visión por computadora</summary>
<br/>

Plataforma SaaS de detección de agresión y bullying en tiempo real mediante cámaras de seguridad. Motor de IA con YOLOv8s (detección de personas), MediaPipe (estimación de pose) y un ensemble de Machine Learning (Random Forest + XGBoost + Gradient Boosting) con AUC-ROC de 0.9557 y recall de 96.5%.
